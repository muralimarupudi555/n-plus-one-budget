# Captured output

Generated by `tools/capture_cli.py`, which runs the real command against a real page load against a real PostgreSQL and records what came back. Regenerated by `make bench`; the query counts are exact and only the timings move.

## A page that loads its children one at a time

```console
$ n-plus-one-budget --strategy n_plus_one --parents 100
n_plus_one, 100 parents with 4 children each, simulated round trip 0ms

reading                               measured   derived
--------------------------------------------------------
queries issued                             101       101
rows returned                              500
payload characters                       25668
median wall time                       12.88 ms
run to run spread                        1.23x
budget                                       2

this page issued 101 queries against a budget of 2: 99 more round trips than it needs.
What those extra trips cost depends entirely on how far away the database is:
  at 0.05 ms round trip        4.95 ms added
  at  0.5 ms round trip       49.50 ms added
  at    1 ms round trip       99.00 ms added
  at    2 ms round trip      198.00 ms added
  at    5 ms round trip      495.00 ms added
The first of those is a developer machine. The last is another region.
$ echo $?
4
```

## The same page as a join, which the counter approves of

```console
$ n-plus-one-budget --strategy join --parents 100 --bio-width 2000
join, 100 parents with 4 children each, simulated round trip 0ms

reading                               measured   derived
--------------------------------------------------------
queries issued                               1         1
rows returned                              400
payload characters                      808920
median wall time                        3.41 ms
run to run spread                        1.33x
budget                                       2

one query, but 600000 characters of it are parent rows sent again: a join repeats every parent column on every child.
A query counter cannot see that, which is worth knowing about query counters.
$ echo $?
0
```
